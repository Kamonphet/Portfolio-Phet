## 📖 เกี่ยวกับโปรเจกต์ (About Project)

**CyberArt 3D Portfolio** คือเว็บไซต์พอร์ตโฟลิโอส่วนบุคคลของ **ครูเพชร IT** ที่ผสมผสานศาสตร์ทางด้าน:
1. **การจัดการเรียนรู้ & นวัตกรรมการศึกษา (EdTech & Active Learning)** — วิทยาการคำนวณและสื่อการสอนสมัยใหม่
2. **ความมั่นคงปลอดภัยทางไซเบอร์ (Cybersecurity & CTF Defense)** — การสร้างความตระหนักรู้และการฝึกทักษะความปลอดภัยดิจิทัล
3. **วิศวกรรมเว็บและกราฟิก 3 มิติ (Modern Web & 3D Interactive)** — ประสบการณ์ผู้ใช้ระดับพรีเมียมด้วย Three.js และ Framer Motion

## ✨ จุดเด่นและฟีเจอร์ (Features)

| หมวดหมู่ | รายละเอียดฟีเจอร์ |
| :--- | :--- |
| 🎮 **Interactive 3D & Cyber Atmosphere** | จำลองเอฟเฟกต์ Background Canvas อนุภาคแสง Cyber Particle และโมเดล 3 มิติเชิงโต้ตอบด้วย Three.js WebGL |
| 🌓 **Dual Cyber Theme Mode** | สลับโหมดการแสดงผล **Dark Mode (Cyber Neon)** และ **Light Mode (Clean Sci-Fi)** ได้ลื่นไหล พร้อมบันทึกสถานะลงใน LocalStorage |
| 🌐 **Bilingual Support (TH / EN)** | รองรับการเปลี่ยนภาษาทั้งภาษาไทยและภาษาอังกฤษได้ครบทุกหมวดหมู่ |
| ✏️ **Live In-Place Content Editor** | ระบบแก้ไขเนื้อหาบนหน้าเว็บได้โดยตรง (In-Place CMS) รองรับการปรับแต่งข้อความและข้อมูลส่วนตัวได้ทันที |
| 🔐 **Encrypted Data Backup & Restore** | ระบบสำรองและกู้คืนข้อมูลด้วยการเข้ารหัสความปลอดภัย ป้องกันข้อมูลสูญหาย |
| 🖼️ **Kru Petch Sticker Showcase** | คอลเลกชันสติกเกอร์และตัวละครประจำตัวครูเพชร IT สำหรับใช้ในสื่อการสอนและการสื่อสาร |
| 📱 **Fully Responsive Design** | รองรับการแสดงผลทุกขนาดหน้าจอ ตั้งแต่มือถือ แท็บเล็ต ไปจนถึงเดสก์ท็อปจอความละเอียดสูง |

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

### Core & Frameworks
- **[React 18](https://react.dev/)** — UI Library ประสิทธิภาพสูง พร้อม Component-driven Architecture
- **[Vite 7](https://vitejs.dev/)** — Next Generation Frontend Tooling รวดเร็วระดับเสี้ยววินาที

### 3D Graphics & Animations
- **[Three.js](https://threejs.org/)** — WebGL 3D Graphics Engine สำหรับวัตถุลอยและสภาพแวดล้อมไซเบอร์
- **[Framer Motion](https://www.framer.com/motion/)** — ระบบ Micro-interactions และ Page Transitions
- **[Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)** — Interactive Celebration Effects

### Styling & Design System
- **Vanilla CSS (Design Tokens & HSL Variables)** — ระบบ Theme และ Glassmorphism ที่ยืดหยุ่นสูง
- **Typography** — Google Fonts (`JetBrains Mono`, `Outfit`, `Prompt`)
- **Icons** — `lucide-react` & `react-icons`

## ⚡ การติดตั้งและเริ่มต้นใช้งาน (Getting Started)

### ความต้องการของระบบ (Prerequisites)
- [Node.js](https://nodejs.org/) (เวอร์ชัน 18.0 ขึ้นไป แนะนำเวอร์ชัน LTS)
- [Git](https://git-scm.com/)

### ขั้นตอนการรันบนเครื่อง Local:

1. **โคลนคลังโค้ดนี้:**
   ```bash
   git clone https://github.com/Kamonphet/Portfolio-Phet.git
   cd Portfolio-Phet
   ```

2. **ติดตั้ง dependencies ทั้งหมด:**
   ```bash
   npm install
   ```

3. **รัน Development Server:**
   ```bash
   npm run dev
   ```
   > เปิดเบราว์เซอร์ไปที่: `http://localhost:5173/`

4. **คำสั่งอื่นๆ ที่สำคัญ:**
   ```bash
   # สร้าง Production Bundle
   npm run build

   # ทดสอบเปิดดู Production Preview
   npm run preview

   # ตรวจสอบโค้ดด้วย Linter
   npm run lint
   ```
